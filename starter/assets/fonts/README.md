# ฟอนต์ไทยของโปรเจค

ฟอนต์ 3 ตระกูล น้ำหนักละ 3 แบบ (Regular · SemiBold · Bold) โหลดจาก
[repo ทางการของ Google Fonts](https://github.com/google/fonts) · สัญญาอนุญาต **OFL** ใช้เชิงพาณิชย์ได้

| ตระกูล | บุคลิก | เหมาะกับ |
|---|---|---|
| **Sarabun** | ทางการ เรียบ อ่านง่ายที่สุดในสามตัว หัวตัวอักษรชัด | ข้อความยาว · คำอธิบายสเปก · ซับไตเติล |
| **Kanit** | หนา ทึบ เหลี่ยม มีน้ำหนักที่สุด | **CTA · ตัวเลข · คำสั้นๆ ที่ต้องเด้ง** |
| **Prompt** | กลมมน เป็นมิตร โปร่งกว่า Kanit | ชื่อสินค้า · แคปชันบนจอ · โทนอบอุ่น |

## ใช้กับ ffmpeg

**ffmpeg ในเครื่องนี้ build มากับ libharfbuzz** จึงทำ text shaping ภาษาไทยได้ถูกต้อง —
สระบน สระล่าง วรรณยุกต์ ตัวการันต์ วางตำแหน่งถูกหมด **ทดสอบแล้วทั้งสามฟอนต์**

อ้างด้วย path ตรงๆ ไม่ต้องพึ่งฟอนต์ที่ลงในระบบ (ยกไปเครื่องอื่นก็ยังทำงาน):

```bash
ffmpeg -i in.mp4 -vf "drawtext=\
fontfile='D\:/ShopeeAffiliate/HomeyVibes-Timelapse/assets/fonts/Kanit-Bold.ttf':\
text='ลิงก์อยู่คอมเมนต์แรก':fontcolor=0xF5C518:fontsize=54:\
x=(w-tw)/2:y=h*0.80:enable='gte(t,24)'" out.mp4
```

> ⚠️ **บน Windows ต้อง escape เป็น `D\:/...` และใช้ `/` ไม่ใช่ `\`** ใน `fontfile=`
> ไม่งั้น ffmpeg อ่าน `:` เป็นตัวคั่นพารามิเตอร์แล้วพัง

**ตำแหน่งตัวหนังสือ** ต้องอยู่สูงกว่าขอบล่างอย่างน้อย 15% (`y=h*0.80` หรือน้อยกว่า)
ไม่งั้นโดน UI ของ Facebook ทับ

## ลงในระบบแล้วด้วย

ติดตั้งแบบ per-user ไว้ที่ `%LOCALAPPDATA%\Microsoft\Windows\Fonts` + ลงทะเบียนใน
`HKCU\Software\Microsoft\Windows NT\CurrentVersion\Fonts` — **ไม่ต้องใช้สิทธิ์ผู้ดูแลระบบ**

แปลว่า CapCut · Canva · Word · โปรแกรมอื่นๆ เห็นฟอนต์เหล่านี้ด้วย
**แต่โปรแกรมที่เปิดค้างอยู่ตอนติดตั้งต้องปิดแล้วเปิดใหม่ถึงจะเห็น**
