# ชุดทำคลิป timelapse ตกแต่งบ้าน

ปลั๊กอิน Claude Code สำหรับทำ Reels แนว **timelapse การตกแต่ง** ที่มีสินค้าแอฟฟิลิเอตอยู่ในคลิป
เดินเรื่อง **4 เฟส 3 คลิป** — ว่างเปล่า → ระหว่างทำ → งานเสร็จแต่ยังไม่จัดของ → จัดของเสร็จ
โดยกล้องนิ่งอยู่มุมเดิมเป๊ะทั้งสี่เฟส

ติดตั้งปลั๊กอินอย่างเดียวจบ — **โครงโปรเจคเปล่ามาพร้อมในตัวปลั๊กอินแล้ว**
(`plugins/aff-timelapse/starter/` มีคู่มือ ตัวตรวจ และฟอนต์) สั่ง `/aff-timelapse:init`
แล้วมันจะถามว่าอยากเก็บโฟลเดอร์งานไว้ที่ไหน แล้วสร้างให้

---

## ขั้นที่ 1 — เตรียมเครื่อง

| ต้องมี | ใช้ทำอะไร | ไม่มีแล้วเป็นยังไง |
|---|---|---|
| **Chrome จริง** ต่อกับ `claude-in-chrome` | เปิดหน้า Shopee เก็บข้อมูลสินค้า | เก็บสินค้าไม่ได้เลย |
| `node` | สคริปต์โหลดรูป + ตัวตรวจฉาก | โหลดรูปกับตรวจงานไม่ได้ |
| `ffmpeg` + `ffprobe` | รวมคลิปกับตรวจคลิป | ทำถึงขั้นสุดท้ายไม่ได้ |
| บัญชี **Higgsfield** | ยิงภาพกับวิดีโอ | ไม่มีภาพให้ทำคลิป |
| `codex` CLI (ล็อกอิน ChatGPT) | อ่านดีไซน์สินค้าจากรูป | ข้ามได้ ต้องเขียนคำบรรยายเอง คุณภาพภาพจะตกลง |

> **วิดีโอต้องยิงบนหน้าเว็บ Higgsfield เท่านั้น** โปรโมชั่น unlimited อยู่ที่นั่น
> ยิงผ่าน MCP คิดเครดิตเต็มราคา — ส่วนภาพยิงผ่าน MCP ได้ (~2 เครดิต/ใบ)

## ขั้นที่ 2 — ติดตั้งปลั๊กอิน

โคลน repo นี้ลงเครื่องก่อน แล้วสั่งใน Claude Code:

```bash
claude plugin marketplace add <path ที่โคลนไว้>
```

แล้วติดตั้ง:

```bash
claude plugin install aff-timelapse@homey-vibes
```

(ในเซสชันโต้ตอบใช้ `/plugin marketplace add …` กับ `/plugin install …` ได้เหมือนกัน
ถ้าผลลัพธ์บอกให้ `/reload-plugins` ก็สั่งตาม)

**อัปเดตทีหลัง** — เจ้าของ repo push ของใหม่ แล้วสั่ง `/plugin marketplace update homey-vibes`

## ขั้นที่ 3 — สร้างโฟลเดอร์งาน

เปิด Claude Code ที่ไหนก็ได้ แล้วสั่ง:

```
/aff-timelapse:init
```

มันจะ**ถามก่อนว่าจะเก็บโฟลเดอร์งานไว้ที่ไหน** (กดเลือกจากที่เสนอ หรือพิมพ์ path เองก็ได้)
แล้วสร้าง `CLAUDE.md` · `Timelapse_Blueprint_V1.md` · `tools/` · `assets/fonts/` · `products/` · `scenes/` ให้ครบ

ใส่ path มาเลยก็ได้ถ้ารู้อยู่แล้ว — `/aff-timelapse:init ~/HomeyVibes-Timelapse`

จากนั้น**เปิดเซสชันใหม่ในโฟลเดอร์นั้น** `CLAUDE.md` ถึงจะถูกอ่าน
และควรอ่าน `Timelapse_Blueprint_V1.md` ก่อนเริ่มงานจริง มันอธิบายเหตุผลเบื้องหลังทุกขั้น

> **ตัวตรวจอยู่ในโฟลเดอร์งาน ไม่ได้อยู่ในปลั๊กอิน** — `node tools/check-scene.mjs`
> เป็นด่านที่คู่มือบังคับให้ผ่านก่อนไปขั้นถัดไป ข้ามขั้นนี้แล้วจะไม่มีตัวตรวจ

## ขั้นที่ 4 — ลองใช้

เปิด Claude Code ในโฟลเดอร์งาน แล้ววางลิงก์สินค้า Shopee:

```
/aff-timelapse:scene <ลิงก์ Shopee>
```

**ไม่ใช่งานรันรวดเดียวจบ** มีจุดหยุดรอ 3 จุดที่ต้องไปยิงภาพกับวิดีโอบนเว็บ Higgsfield เอง
ถ้าอยากทำทีละขั้นให้เรียกสกิลย่อยตรงๆ:

| คำสั่ง | ทำอะไร |
|---|---|
| `/aff-timelapse:product <ลิงก์>` | เก็บสินค้าจาก Shopee |
| `/aff-timelapse:idea <slug>` | ไอเดีย 4 แบบให้กดเลือก → CAMERA LOCK + พรอมต์ Phase 4 (ภาพหมุด) |
| `/aff-timelapse:phase3` `phase2` `phase1` | พรอมต์แก้ภาพถอยหลังจากภาพหมุด |
| `/aff-timelapse:storyboard <scene>` | สตอรีบอร์ด 3 ช่วง ช่วงละ 8 วิ + ตรวจคลิป |
| `/aff-timelapse:assemble <scene>` | รวมคลิป 9:16 ด้วย ffmpeg |

---

## สามข้อที่พลาดกันบ่อยที่สุด

1. **Phase 4 ต้องทำก่อนเสมอ** อีกสามเฟสเกิดจากการ *แก้ภาพ* Phase 4 โดยตรงทุกใบ —
   ไม่ใช่ไล่ 1→2→3→4 ซึ่งสะสมความเพี้ยนสามทอด
2. **ตอนยิงวิดีโอต้องเปิดสวิตช์ Sound** เสียง ASMR มาจากโมเดลวิดีโอ ลืมแล้วต้องยิงใหม่ทั้งคลิป
   แก้ทีหลังไม่ได้
3. **ตรวจด้วยคำสั่ง ไม่ใช่ด้วยตา** → `node tools/check-scene.mjs scenes/<slug>`
   เคยปล่อยคลิปแขนลอยผ่านมาแล้วเพราะดูผ่านๆ

## สำหรับเจ้าของชุด — แก้แล้วปล่อยรุ่นยังไง

repo นี้คือ**แหล่งเดียว**ของปลั๊กอิน เครื่องที่พัฒนาต่อชี้เข้ามาด้วย junction แทนการก๊อป:

```bash
cmd //c mklink //J "%USERPROFILE%\.claude\skills\aff-timelapse" "<path ของ repo>\plugins\aff-timelapse"
```

แล้วปลั๊กอินจะโหลดเป็น `aff-timelapse@skills-dir` โดยอ่านไฟล์จาก repo ตรงๆ —
**แก้ `SKILL.md` แล้วมีผลในเซสชันปัจจุบันทันที** ไม่ต้องติดตั้งใหม่ และ git เห็นทุกการแก้

พอจะส่งของใหม่ให้เพื่อน:

```powershell
.\release.ps1 1.5.1 "สรุปสั้นๆ ว่าแก้อะไร"
```

สคริปต์จะเลื่อนเลขเวอร์ชันทั้งใน `plugin.json` และ `marketplace.json` · ดักไม่ให้มี path
ที่ออกนอกโฟลเดอร์ปลั๊กอิน · รัน `claude plugin validate` ทั้งสองชั้น · commit + tag + push

> ⚠️ **ห้ามปล่อยรุ่นโดยไม่เลื่อนเลขเวอร์ชัน** ถ้าเลขเท่าเดิม Claude Code เห็นว่าเวอร์ชันเดียวกัน
> แล้ว**ข้ามการอัปเดตไปเงียบๆ** เพื่อนจะยังใช้ของเก่าอยู่โดยไม่มีใครรู้ตัว
> ฝั่งเจ้าของไม่มีทางสังเกตเห็นด้วย เพราะฝั่งเจ้าของแก้สดผ่าน junction อยู่แล้ว

**ข้อควรระวังของการพัฒนาผ่าน junction** — ฝั่งเจ้าของยังเห็นไฟล์รอบข้างในเครื่อง
แต่ฝั่งเพื่อนปลั๊กอินถูกก๊อปเข้า cache ของมันเอง ถ้าเผลอเขียน path ที่วิ่งออกนอกโฟลเดอร์ปลั๊กอิน
**ฝั่งเจ้าของจะไม่พัง แต่ฝั่งเพื่อนพัง** — `release.ps1` ดักข้อนี้ให้ก่อน push ทุกครั้ง
