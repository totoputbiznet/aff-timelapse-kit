# ชุดทำคลิป timelapse ตกแต่งบ้าน

ปลั๊กอิน Claude Code สำหรับทำ Reels แนว **timelapse การตกแต่ง** ที่มีสินค้าแอฟฟิลิเอตอยู่ในคลิป
เดินเรื่อง **4 เฟส 3 คลิป** — ว่างเปล่า → ระหว่างทำ → งานเสร็จแต่ยังไม่จัดของ → จัดของเสร็จ
โดยกล้องนิ่งอยู่มุมเดิมเป๊ะทั้งสี่เฟส

ในนี้มีสองส่วน **ต้องเอาไปทั้งคู่**

| ส่วน | คืออะไร | เอาไปไว้ไหน |
|---|---|---|
| `plugins/aff-timelapse/` | ตัวปลั๊กอิน 9 สกิล | ติดตั้งผ่าน Claude Code (ขั้นที่ 2) |
| `starter/` | โครงโปรเจคเปล่า — คู่มือ ตัวตรวจ ฟอนต์ | ก๊อปไปเป็นโฟลเดอร์งานของตัวเอง (ขั้นที่ 3) |

**ตัวตรวจอยู่ใน `starter/tools/` ไม่ได้อยู่ในปลั๊กอิน** ลงแค่ปลั๊กอินอย่างเดียวจะรัน
`node tools/check-scene.mjs` ไม่ได้ ซึ่งเป็นด่านที่คู่มือบังคับให้ผ่านก่อนไปขั้นถัดไป

---

## ขั้นที่ 1 — เตรียมเครื่อง

| ต้องมี | ใช้ทำอะไร | ไม่มีแล้วเป็นยังไง |
|---|---|---|
| **Chrome จริง** ต่อกับ `claude-in-chrome` | เปิดหน้า Shopee เก็บข้อมูลสินค้า | เก็บสินค้าไม่ได้เลย |
| `node` | สคริปต์โหลดรูป + ตัวตรวจฉาก | โหลดรูปกับตรวจงานไม่ได้ |
| `ffmpeg` + `ffprobe` | รวมคลิปกับตรวจคลิป | ทำถึงขั้นสุดท้ายไม่ได้ |
| บัญชี **Higgsfield** | ยิงภาพกับวิดีโอ | ไม่มีภาพให้ทำคลิป |
| `codex` CLI (ล็อกอิน ChatGPT) | อ่านดีไซน์สินค้าจากรูป | ข้ามได้ ต้องเขียนคำบรรยายเอง คุณภาพภาพจะตกลง |

> **วิดีโอต้องยิงบนหน้าเว็บ Higgsfield เท่านั้น** โปรโมชั่น unlimited อยู่ที่นั่น
> ยิงผ่าน MCP คิดเครดิตเต็มราคา — ส่วนภาพยิงผ่าน MCP ได้ (~2 เครดิต/ใบ)

## ขั้นที่ 2 — ติดตั้งปลั๊กอิน

โคลน repo นี้ลงเครื่องก่อน แล้วสั่งใน Claude Code:

```bash
claude plugin marketplace add <path ที่โคลนไว้>
```

แล้วติดตั้ง:

```bash
claude plugin install aff-timelapse@homey-vibes
```

(ในเซสชันโต้ตอบใช้ `/plugin marketplace add …` กับ `/plugin install …` ได้เหมือนกัน
ถ้าผลลัพธ์บอกให้ `/reload-plugins` ก็สั่งตาม)

**อัปเดตทีหลัง** — เจ้าของ repo push ของใหม่ แล้วสั่ง `/plugin marketplace update homey-vibes`

## ขั้นที่ 3 — สร้างโฟลเดอร์งาน

ก๊อป `starter/` ทั้งก้อนไปเป็นโฟลเดอร์โปรเจคของตัวเอง เช่น

```bash
cp -r starter ~/my-timelapse-project
```

ในนั้นมี `CLAUDE.md` ที่ Claude Code จะอ่านเองทุกครั้งที่เปิดเซสชันในโฟลเดอร์นั้น
กับ `Timelapse_Blueprint_V1.md` ที่อธิบายเหตุผลเบื้องหลังทุกขั้น — **อ่านก่อนเริ่มงานจริง**

## ขั้นที่ 4 — ลองใช้

เปิด Claude Code ในโฟลเดอร์งาน แล้ววางลิงก์สินค้า Shopee:

```
/aff-timelapse:scene <ลิงก์ Shopee>
```

**ไม่ใช่งานรันรวดเดียวจบ** มีจุดหยุดรอ 3 จุดที่ต้องไปยิงภาพกับวิดีโอบนเว็บ Higgsfield เอง
ถ้าอยากทำทีละขั้นให้เรียกสกิลย่อยตรงๆ:

| คำสั่ง | ทำอะไร |
|---|---|
| `/aff-timelapse:product <ลิงก์>` | เก็บสินค้าจาก Shopee |
| `/aff-timelapse:idea <slug>` | ไอเดีย 5 แบบ → CAMERA LOCK + พรอมต์ Phase 4 (ภาพหมุด) |
| `/aff-timelapse:phase3` `phase2` `phase1` | พรอมต์แก้ภาพถอยหลังจากภาพหมุด |
| `/aff-timelapse:storyboard <scene>` | สตอรีบอร์ด 3 ช่วง ช่วงละ 8 วิ + ตรวจคลิป |
| `/aff-timelapse:assemble <scene>` | รวมคลิป 9:16 ด้วย ffmpeg |

## สามข้อที่พลาดกันบ่อยที่สุด

1. **Phase 4 ต้องทำก่อนเสมอ** อีกสามเฟสเกิดจากการ *แก้ภาพ* Phase 4 โดยตรงทุกใบ —
   ไม่ใช่ไล่ 1→2→3→4 ซึ่งสะสมความเพี้ยนสามทอด
2. **ตอนยิงวิดีโอต้องเปิดสวิตช์ Sound** เสียง ASMR มาจากโมเดลวิดีโอ ลืมแล้วต้องยิงใหม่ทั้งคลิป
   แก้ทีหลังไม่ได้
3. **ตรวจด้วยคำสั่ง ไม่ใช่ด้วยตา** → `node tools/check-scene.mjs scenes/<slug>`
   เคยปล่อยคลิปแขนลอยผ่านมาแล้วเพราะดูผ่านๆ
