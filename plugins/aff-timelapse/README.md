# aff-timelapse — ชุดเครื่องมือทำ Reels แนว timelapse ตกแต่งบ้าน

ปลั๊กอินของเพจ **Homey Vibes** ทำคลิป before/after การตกแต่งในบ้าน ระเบียงคอนโด และสวน
โดยมีสินค้าแอฟฟิลิเอตอยู่ในคลิป — เดินเรื่อง 3 เฟส **ว่างเปล่า → ระหว่างทำ → เสร็จสวย**
ที่กล้องนิ่งอยู่มุมเดิมเป๊ะทั้งสามเฟส

เอกสารหลักที่อธิบายเหตุผลเบื้องหลังทุกขั้น คือ `Timelapse_Blueprint_V1.md` ในโฟลเดอร์โปรเจค

## เกณฑ์ความตรงของสินค้า — ตัดสินแล้ว

**สินค้าขอแค่ "ใกล้เคียง" ไม่ต้องตรง 100%** ต้องตรงแค่ **ภาพลักษณ์โดยรวม** กับ **ฟังก์ชันการทำงาน**
จำนวนสัน จำนวนชั้น มิติเป๊ะๆ ไม่ต้องตรง — **สินค้าเป็นแค่ตัวอ้างอิง คลิปขายบรรยากาศและผลลัพธ์**

การไล่ให้ตรง 100% ทำให้เสียการยิงภาพหลายรอบโดยที่คลิปไม่คืบเลย
**ภาพผ่านเกณฑ์แล้วให้รับแล้วเดินต่อทันที**

## หลักที่ทั้งชุดยืนอยู่บน

**4 เฟส 3 คลิป · สร้าง Phase 4 ก่อน แล้วลบของออกถอยหลังไปเป็น Phase 3 · 2 · 1**

| เฟส | คืออะไร |
|---|---|
| P1 | ว่างเปล่า ก่อนทำ |
| P2 | ระหว่างทำ มีคนงาน เครื่องมือ วัสดุ |
| P3 | **งานเสร็จ แต่ยังไม่ได้จัดของ** |
| P4 | จัดของเสร็จ ← **ภาพหมุด สร้างก่อนเพื่อน** |

text-to-image สี่ครั้งได้กล้องคนละมุมแน่นอน ต่อให้พรอมต์เหมือนกันทุกตัวอักษร
ทางเดียวที่ล็อกมุมได้จริงคือ image-editing จาก `phase4.png`
**และทุกใบต้องแก้จากภาพหมุดโดยตรง ลึกแค่ทอดเดียว** ไม่ใช่ chain 1→2→3→4 ซึ่งสะสมความเพี้ยนสามทอด

**ทำไมต้องมี P3** — ถ้าให้คลิปเดียวทั้งทำงานให้เสร็จและจัดเฟอร์นิเจอร์ เฟอร์นิเจอร์จะ "โผล่มา"
แทนที่จะถูกยกเข้ามาวาง แยกแล้วแต่ละคลิปทำหน้าที่เดียว **และรอยต่อ P2→P3 กลายเป็นรอยต่อที่เนียนที่สุด**
เพราะทั้งสองฝั่งเป็นสภาพนิ่ง ไม่มีคนขวาง

สกิลทุกตัว**ไม่ได้ยิงภาพหรือวิดีโอเอง** — มันเขียนพรอมต์ให้ก๊อปไปวางบนเว็บ Higgsfield
เพราะโปร unlimited อยู่บนเว็บเท่านั้น (ยิงผ่าน CLI หรือ MCP คิดเครดิตเต็มราคา)

## สิ่งที่ต้องมีในเครื่องก่อนใช้

- **Chrome จริงของผู้ใช้** เชื่อมกับ `claude-in-chrome` — ใช้เปิดหน้า Shopee
- `node` — สคริปต์โหลดรูป `scripts/fetch-images.mjs`
- `ffmpeg` กับ `ffprobe` — ใช้ตอนรวมคลิปกับตรวจคลิป
- `codex` CLI ล็อกอิน ChatGPT — ใช้อ่านดีไซน์สินค้าจากรูป (ไม่มีก็ข้ามได้ แต่คุณภาพภาพจะตก)
- บัญชี **Higgsfield** — ยิงภาพกับวิดีโอบนเว็บ

**ชุดนี้เป็นก้อนเดียวจบตั้งแต่ 1.5.0** ไม่ต้องมีปลั๊กอิน `aff` อีกแล้ว

## เอาไปลงเครื่องใหม่ยังไง

**ทาง A — ก๊อปโฟลเดอร์** วางที่ `~/.claude/skills/aff-timelapse/` แล้วเปิดเซสชันใหม่
มันจะโหลดเองเป็น `aff-timelapse@skills-dir` ไม่ต้องติดตั้งอะไร

**ทาง B — ติดตั้งจาก marketplace** (อัปเดตทีหลังได้ด้วยคำสั่งเดียว)

```bash
claude plugin marketplace add <repo ที่แจก>
```

แล้ว `/plugin install aff-timelapse@homey-vibes`

ตรวจไฟล์ก่อนแจกทุกครั้ง:

```bash
claude plugin validate ~/.claude/skills/aff-timelapse
```

> ปลั๊กอินอย่างเดียวยังทำงานไม่ครบ — ต้องมี**โครงโปรเจค**ด้วย (`CLAUDE.md` · `Timelapse_Blueprint_V1.md`
> · `tools/check-scene.mjs` · `tools/check-phase-prompt.mjs` · `assets/fonts/`) ตัวตรวจอยู่ในโปรเจค ไม่ได้อยู่ในปลั๊กอิน

## กฎที่ต้องระวังตอนแก้ไฟล์ในชุดนี้

**ห้ามเขียนที่อยู่ไฟล์แบบตายตัว** และ**ห้ามอ้างไฟล์นอกโฟลเดอร์ปลั๊กอิน**
ให้ใช้ `${CLAUDE_SKILL_DIR}/../../references/<ไฟล์>` แทนเสมอ —
ตอนติดตั้งจาก marketplace ปลั๊กอินถูกก๊อปเข้า cache ของมันเอง path ที่ออกไปข้างนอกจะพังทันที

    ไม่มีให้เขียนว่าไม่รู้ ห้ามเดา · สองแหล่งขัดกันให้เชื่อแบบเทคนิค
  - `product` + `refsheet` — **แนบ reference หลายใบจากหลายมุม** ใบเดียวไม่พอ
    แต่ห้ามแนบรูปแบบเทคนิคที่มีตัวเลข และห้ามแนบรูปใช้งานจากหน้าร้านที่ขัดกับสินค้าจริง
  - `idea` — **กล่องโค้ดต้องเป็นพรอมต์เต็มใบเสมอ** ห้ามโชว์เฉพาะบล็อกที่แก้
    (เกิดขึ้นจริง: ผู้ใช้ก๊อปเฉพาะ `[PRODUCT]` ไปวาง ได้ทางเดินออฟฟิศแทนระเบียง)
  - `refsheet` — เพิ่มข้อตรวจ นับจำนวนชิ้นส่วนทุกมุมแล้วเทียบกันเอง
