## ขั้นที่ 1 — ความยาวคลิป

**ยิงที่ความยาวจริงตั้งแต่แรก ห้ามยิงยาวแล้วตัดท้ายทีหลัง**
เฟรมสุดท้ายของแต่ละคลิปคือภาพเฟสถัดไป ตัดท้ายทิ้งเมื่อไหร่โซ่ frame-to-frame ขาดทันที

ค่าเริ่มต้น **8 วินาที/คลิป** (รวม ~24 วิ + ค้างภาพจบ 2 วิ = ~26 วิ)
ถ้าเครื่องมือจำกัดช่วงไว้ ให้ถามผู้ใช้ว่ารับได้กี่วินาที แล้วเลือกใกล้ 8 ที่สุด

> ⚠️ โมเดลอาจให้ความยาวคลาดจากที่ตั้ง (ตั้ง 8 ได้ 9) **ไม่ต้องแก้** แค่ปรับไทม์ไลน์ตอนตัดต่อตามจริง

## ขั้นที่ 2 — โครงพรอมต์ 8 บล็อก

```
Overall: · Camera: · Subject: · Action: · Lighting: · Sound Effects: · Dialogue: No · Subtitles: No
```

### `Camera:` — ยัดหมุดอ้างอิงไว้ที่นี่

```
Completely static wide-angle shot, no camera movement whatsoever, fixed perspective
throughout the entire sequence. <หมุดอ้างอิง 3-4 อย่างจาก CAMERA LOCK CARD เป็นประโยคเดียว>
stay in exactly the same place for all <N> seconds.
```

### `Subject:` — บังคับคนเต็มตัว

```
<กี่คน> in <เสื้อผ้าธรรมดา>. Each one is shown FULL BODY, head to feet, walking in
through the frame edge and walking out again. Always seen from behind or in motion
blur, never facing the camera. No disembodied hands or arms - whenever an item is
placed, the whole person who placed it is visible in the frame.
```

### `Action:` ⛔ **ต้องเป็น active voice ขึ้นต้นทุกวรรคด้วยคนทำ**

**นี่คือกฎที่พลาดแล้วเสียคลิปทั้งใบ** วัดมาแล้วจากงานจริง

เขียนแบบ passive voice ทั้งบล็อก:

> *a folded teak chair **is carried in and set down**; a beige cushion **is carried in and placed**; a side table **is carried in, opened and positioned**...*

**ได้ผลลัพธ์เป็นท่อนแขนลอยยื่นเข้ามาจากขอบเฟรม ไม่มีคนเดินเข้ามาสักครั้ง** ดูหลอนกว่าไม่มีคนเลย
เพราะ passive voice เอา**สิ่งของ**ขึ้นเป็นประธานแล้ว**ลบคนทำออกจากประโยค** โมเดลเรนเดอร์ตามนั้นเป๊ะ

เขียนใหม่เป็น active voice **ผ่านทันทีรอบเดียว**:

> *a worker **walks in** from the right carrying a folded teak chair, **sets it down**, **unfolds it** and **walks out**; a second worker **walks in** carrying a beige cushion, **drops it** onto the seat, **pats it flat** and **walks out**...*

**กฎเหล็ก 4 ข้อของบล็อกนี้:**

1. ทุกวรรคขึ้นต้นด้วย `a worker` / `two workers` — **ห้ามขึ้นต้นด้วยชื่อสิ่งของ**
2. วรรคที่มีคนต้องปิดด้วยการเดินออก (`and walks out`)
3. คั่นวรรคด้วย semicolon เรียงตามลำดับเวลาจริง
4. ปิดบล็อกด้วย `No instant appearances.` และ `The final second is completely still and empty of people.`

> หลักฐาน: ในงานจริง seg1 กับ seg2 ได้คนเต็มตัวตั้งแต่รอบแรก เพราะสองใบนั้นเขียนว่า
> *"the worker lifts..."* *"the worker sweeps..."* เป็น active อยู่แล้ว
> มีแต่ seg3 ที่เป็น passive ล้วน แล้วพังใบเดียว

### `Sound Effects:` — เสียง ASMR

```
<เสียง 5-8 อย่างที่มีที่มาให้เห็นในเฟรมจริง>. Dry, close and detailed ASMR quality,
no reverb tail. <ทิศทางของเสียง — ดังขึ้นหรือเบาลง>. NO music.
```

**ขอเฉพาะเสียงที่เห็นที่มาในภาพ** ถ้าในเฟรมไม่มีเลื่อย อย่าขอเสียงเลื่อย
**เสียงสามช่วงต้องไล่ระดับ** — ช่วงแรกดังถี่ ช่วงกลางเริ่มเก็บงาน ช่วงท้ายเหลือแต่บรรยากาศ
นี่คือสิ่งที่ทำให้คลิปมีจุดจบ ไม่ใช่จบเพราะเวลาหมด

**`Dialogue: No` และ `Subtitles: No` ต้องมีทุกใบ** เป็นวิธีสั้นที่สุดที่กันเสียงพูดกับตัวหนังสือได้

## ขั้นที่ 3 — ส่งมอบ

1. **วางพรอมต์ทั้งสามช่วงในกล่องโค้ดแยกกัน ก๊อปได้ทันที เต็มใบทุกใบ**
   ⛔ ห้ามโชว์เฉพาะบล็อกที่แก้ ผู้ใช้จะก๊อปแค่นั้นไปวางแล้วได้คนละฉากกลับมา
2. บอกตั้งค่าให้ครบ: start frame · end frame · ความยาว · 9:16 · **เปิด Sound**
3. **ยิงเสร็จบอกได้เลย ไม่ต้องเซฟไฟล์เอง** — ดึงด้วย Higgsfield MCP `show_generations`
   แบบ `type: "video"` แล้วโหลด `results.rawUrl` ลง `clips/seg1.mp4` `seg2.mp4` `seg3.mp4`
   (การอ่านไม่กินเครดิต · ยืนยัน `params.medias` ว่า start/end image ตรงคู่ก่อนโหลด)

## ขั้นที่ 4 — ตรวจคลิปที่ยิงกลับมา ⭐ ทำทุกครั้ง อย่าดูด้วยตาอย่างเดียว

**ตรวจหลวมแล้วปล่อยคลิปเสียผ่านไปมาแล้ว** ใช้คำสั่งพวกนี้ ไม่ใช่ความรู้สึก

### 4.1 ความยาวกับสตรีม

```bash
ffprobe -v error -show_entries format=duration -show_entries stream=codec_type,width,height,r_frame_rate -of csv=p=0 seg1.mp4
```

ต้องมี **stream เสียง** ด้วย ถ้ามีแต่ video = ลืมเปิด Sound ต้องยิงใหม่

### 4.2 เสียงไม่เงียบจริง

```bash
ffmpeg -hide_banner -i seg1.mp4 -af volumedetect -f null /dev/null 2>&1 | grep -E "mean_volume|max_volume"
```

มีแทร็กเสียงแต่เงียบสนิทเป็นไปได้ **ต้องเห็นตัวเลขจริง** — งานที่ผ่านอยู่ราว mean −25 ถึง −30 dB
ถ้าเห็น −91 dB คือเงียบสนิท ต้องยิงใหม่

### 4.3 รอยต่อตรงกัน

```bash
ffmpeg -v error -y -sseof -0.09 -i seg1.mp4 -frames:v 1 -vf scale=300:-1 a.png
ffmpeg -v error -y -i seg2.mp4 -frames:v 1 -vf scale=300:-1 b.png
ffmpeg -v error -y -i a.png -i b.png -filter_complex hstack seam.png
```

เปิด `seam.png` ดู **ของนิ่งทุกชิ้นต้องอยู่ตำแหน่งเดียวกัน** (เครื่องมือ วัสดุ เงา ราว วิว)
คนโผล่หรือหายได้ ไม่ถือว่าผิด — timelapse เป็นแบบนั้นอยู่แล้ว

### 4.4 กล้องนิ่งจริงภายในคลิป

```bash
ffmpeg -v error -y -i first.png -i last.png -filter_complex "[0][1]blend=all_mode=difference,eq=brightness=0.3:contrast=4" drift.png
```

**ถ้ากล้องนิ่ง โซนที่ไม่มีอะไรเปลี่ยน (ท้องฟ้า ราวกันตก ฝ้า) จะเรียบสนิท**
ถ้ากล้องขยับแม้แต่นิดเดียว เส้นคอนทราสต์สูงทั้งเฟรม (ซี่ราว รอยต่อกระเบื้อง) จะเรืองขึ้นหมด

### 4.5 ดูทีละเฟรมว่าคนเต็มตัวไหม

```bash
ffmpeg -v error -y -i seg3.mp4 -vf "select='not(mod(n\,16))',scale=240:-1" -vsync 0 c%d.jpg
```

แล้วต่อเป็น contact sheet ด้วย `hstack`/`vstack` **ดูทุกช่องว่าเห็นคนตั้งแต่หัวถึงเท้าไหม**
เห็นแค่มือหรือแขนยื่นเข้ามา = **ไม่ผ่าน** ให้แก้ `Action:` เป็น active voice แล้วยิงใหม่

### เกณฑ์ตัดสิน

| เจออะไร | ผ่าน/ไม่ผ่าน | แก้ยังไง |
|---|---|---|
| ไม่มี stream เสียง หรือ −91 dB | ❌ | ยิงใหม่ เปิด Sound · **แก้ทีหลังไม่ได้** |
| มีดนตรีหรือเสียงพูด | ❌ | เติม `NO music.` `Dialogue: No` แล้วยิงใหม่ |
| แขนลอย ไม่เห็นคนเต็มตัว | ❌ | แก้ `Action:` เป็น active voice + `FULL BODY` ใน `Subject:` |
| กล้องขยับ | ❌ | ย้ำ `no camera movement whatsoever, fixed perspective throughout` |
| ของนิ่งไม่ตรงที่รอยต่อ | ❌ | เช็คว่าใช้ไฟล์ภาพเฟสเดียวกันจริงทั้งสองคลิป |
| คนโผล่/หายตรงรอยต่อ | ✅ | ปกติของ timelapse ปล่อยได้ |
| ความยาวคลาดจากที่ตั้ง 1 วิ | ✅ | ปรับไทม์ไลน์ตามจริง |
| ของชิ้นเล็กหายไปช่วงท้าย | ✅ ถ้าเป็นคลิปสุดท้าย | ไม่มีรอยต่อถัดไปแล้ว ภาพจบยังสมบูรณ์ในตัว |

**ไม่ผ่านให้บอกผู้ใช้ว่าไม่ผ่านเพราะอะไร พร้อมพรอมต์ที่แก้แล้วเต็มใบ** อย่าบอกแค่ว่า "ยิงใหม่"
