## ก่อนเริ่ม — ตรวจของเข้า

`clips/seg1.mp4` · `seg2.mp4` · `seg3.mp4` ทุกไฟล์ต้อง**มีแทร็กเสียงและเสียงไม่เงียบ**

```bash
for f in seg1 seg2 seg3; do
  ffprobe -v error -show_entries format=duration -show_entries stream=codec_type -of csv=p=0 clips/$f.mp4
  ffmpeg -hide_banner -i clips/$f.mp4 -af volumedetect -f null /dev/null 2>&1 | grep mean_volume
done
```

คลิปไหนไม่มี stream เสียง หรือ mean ต่ำกว่า −80 dB = ลืมเปิด Sound ตอนยิง
**บอกให้ยิงใหม่ อย่าหาเสียงมาแปะแทน** เสียงต้องมาจากโมเดลเพื่อให้ตรงกับภาพเป๊ะ

**อย่าเชื่อความยาวที่ตั้งไว้ ให้อ่านจาก `ffprobe` เสมอ** โมเดลมักคลาดไป 1 วินาที

## ขั้นที่ 1 — รวมด้วย ffmpeg (วิธีที่ใช้จริงและได้ผล)

> **คำสั่งเดียวจบ** — ต่อคลิป ค้างเฟรมจบ fade เสียง ไม่มีชั้นตัวหนังสือ
> เดิมสกิลนี้เขียนให้ใช้ hyperframes แต่งานจริงใช้ ffmpeg ตรงกว่าและไม่ต้องเรนเดอร์ HTML

```bash
ffmpeg -hide_banner -v error -y \
  -i clips/seg1.mp4 -i clips/seg2.mp4 -i clips/seg3.mp4 -filter_complex "\
[0:v]setpts=PTS-STARTPTS,fps=24[v0];[1:v]setpts=PTS-STARTPTS,fps=24[v1];[2:v]setpts=PTS-STARTPTS,fps=24[v2];\
[0:a]asetpts=PTS-STARTPTS[a0];[1:a]asetpts=PTS-STARTPTS[a1];[2:a]asetpts=PTS-STARTPTS[a2];\
[v0][a0][v1][a1][v2][a2]concat=n=3:v=1:a=1[vc][ac];\
[vc]tpad=stop_mode=clone:stop_duration=2[vout];\
[ac]apad=pad_dur=2,afade=t=out:st=<รวมคลิป-0.5>:d=2.5[aout]" \
  -map "[vout]" -map "[aout]" \
  -c:v libx264 -crf 18 -preset medium -pix_fmt yuv420p -movflags +faststart \
  -c:a aac -b:a 192k final/reel.mp4
```

**จุดที่ต้องคำนวณเอง:** `afade` เริ่มที่ **ความยาวรวมของสามคลิป ลบ 0.5 วินาที**
(เช่น 10.08 + 9.06 + 8.06 = 27.2 → `st=26.7`) แล้ว fade ยาว 2.5 วิ ให้จบพอดีกับภาพค้าง

**อะไรทำอะไร:**

| ท่อน | ทำอะไร |
|---|---|
| `fps=24` | บังคับเฟรมเรตให้ตรงกันก่อน concat กันภาพกระตุก |
| `concat=n=3:v=1:a=1` | ต่อทั้งภาพและเสียงพร้อมกัน **รอยต่อเป็น cut ตรงๆ ไม่ dissolve** |
| `tpad=stop_mode=clone:stop_duration=2` | ค้างเฟรมสุดท้าย 2 วินาที |
| `apad` + `afade` | ต่อความเงียบให้เท่าภาพค้าง แล้ว fade เสียงลง |
| `-crf 18` | คุณภาพสูง ไฟล์ยังเล็กพอ |

## ขั้นที่ 3 — ตัวหนังสือบนจอ ⛔ **ไม่ทำ เว้นแต่ผู้ใช้สั่งมาเอง**

**เจ้าของโปรเจคตัดสินแล้วว่ารีลที่ส่งออกต้องไม่มีตัวหนังสือ** — `final/reel.mp4` เป็นภาพกับเสียงล้วน
**ห้ามใส่ให้เอง ห้ามเสนอ** ผู้ใช้จะไปจัดการชั้นตัวหนังสือเองทีหลัง

> เหตุผลที่เดาได้ (ไม่ต้องถาม): ส่งไฟล์สะอาดออกมาแล้วไปใส่ตัวหนังสือตอนโพสต์
> ยืดหยุ่นกว่า — เปลี่ยนคำได้โดยไม่ต้องเรนเดอร์วิดีโอใหม่ และเอาไปใช้ซ้ำหลายแพลตฟอร์มได้

**ถ้าผู้ใช้สั่งมาเองว่าอยากได้ตัวหนังสือ** ค่อยทำ และทำด้วย ffmpeg ได้เลย ไม่ต้องพึ่ง hyperframes —
ffmpeg ในเครื่องนี้ build มากับ **libharfbuzz** จึงวางสระ วรรณยุกต์ ตัวการันต์ ภาษาไทยถูกต้อง

ฟอนต์อยู่ที่ `assets/fonts/` (Sarabun · Kanit · Prompt อย่างละ 3 น้ำหนัก)
ชุดที่จัดไว้: **ชื่อสินค้า = Prompt SemiBold · CTA = Kanit Bold**

```bash
drawtext=fontfile='D\:/<path>/assets/fonts/Kanit-Bold.ttf':text='ลิงก์อยู่คอมเมนต์แรก':\
fontcolor=0xF5C518:fontsize=52:box=1:boxcolor=black@0.5:boxborderw=18:\
x=(w-tw)/2:y=h*0.76:enable='gte(t,24.4)'
```

> ⚠️ **บน Windows ต้อง escape เป็น `D\:/...` และใช้ `/` ไม่ใช่ `\`** ใน `fontfile=`
> ไม่งั้น ffmpeg อ่าน `:` เป็นตัวคั่นพารามิเตอร์แล้วพัง

- ตัวหนังสือต้องอยู่ **สูงกว่าขอบล่างอย่างน้อย 15%** (`y=h*0.76` ปลอดภัย) ไม่งั้นโดน UI ของ Facebook ทับ
- **CTA ใช้ว่า "ลิงก์อยู่คอมเมนต์แรก"** — ไม่ใช่การขอไลก์ขอแชร์ จึงไม่เข้าข่าย engagement bait
- **ห้ามใส่ราคาในคลิป** ราคาบน Shopee เปลี่ยนตลอด คลิปอยู่ยาวกว่าราคา

## กฎเหล็ก

| เจออะไร | แปลว่า | ทำยังไงต่อ |
|---|---|---|
| คลิปไหนเงียบสนิท | ลืมเปิด Sound | บอกให้ยิงใหม่ **ห้ามหาเสียงมาแปะแทน** |
| ความยาวไม่ตรงที่ตั้ง | โมเดลคลาด | ปรับ `afade` ตามความยาวจริงจาก `ffprobe` |
| เฟรมเรตไม่เท่ากัน | คลิปมาจากคนละรอบ | `fps=24` ในฟิลเตอร์จัดการให้แล้ว |
| ขาด seg ไหน | คลิปไม่ครบ | หยุด บอกว่าขาดท่อนไหน **อย่าต่อแค่ที่มีแล้วบอกว่าเสร็จ** |
| อยากใส่ตัวหนังสือให้เอง | — | ⛔ **อย่า** ส่งไฟล์สะอาดออกมา ผู้ใช้จัดการชั้นตัวหนังสือเอง |
| `ffmpeg` ไม่มีในเครื่อง | — | ยังส่ง `caption.md` กับไทม์ไลน์ให้ครบ แล้วบอกว่าเรนเดอร์ไม่ได้เพราะอะไร |

**ห้ามใส่ BGM เองในทุกกรณี** ต่อให้คิดว่าเพราะกว่า — เสียง ASMR คือสินค้าหลักของคลิปแนวนี้
ถ้าผู้ใช้สั่งมาเองค่อยใส่ และให้เบากว่าเสียงคลิปอย่างน้อย 20 dB

**ห้าม normalize หรือ mute เสียงต้นฉบับ** เอามาทั้งดุ้น
