## จังหวะการทำงาน — รายงานแล้วไปต่อเอง

จบขั้นไหน **รายงานผลสั้นๆ 1-3 บรรทัดแล้วทำขั้นถัดไปต่อทันที** ไม่ต้องขออนุญาต
รายงานให้บอก**ผลที่วัดได้** (ได้ไฟล์อะไร กี่รูป ผ่านหรือไม่ผ่าน) ไม่ใช่บอกว่ากำลังจะทำอะไร

**หยุดรอผู้ใช้เฉพาะ 3 กรณีนี้เท่านั้น:**

| หยุดเมื่อ | ตัวอย่าง |
|---|---|
| ต้องให้ผู้ใช้**ตัดสินใจ** | เลือกไอเดีย · รับหรือไม่รับภาพ · จะเขียนทับของเดิมไหม |
| ต้องให้ผู้ใช้**ไปทำเองบนเว็บ** | ยิงภาพหรือวิดีโอที่ Higgsfield |
| **ติดปัญหาที่แก้เองไม่ได้** | Chrome ไม่เชื่อมต่อ · ไม่มีไฟล์ที่ต้องใช้ · คำสั่งที่ต้องใช้ไม่มีในเครื่อง |

นอกจากสามข้อนี้ **ห้ามถามว่า "จะให้ทำต่อไหม"** — ทำต่อได้เลย
ขั้นที่พังไม่ได้แปลว่าต้องหยุดทั้งงาน **ทำขั้นที่เหลือให้จบแล้วค่อยบอกว่าขั้นไหนไม่สำเร็จเพราะอะไร**

## ขั้นที่ 1 — ถามก่อนว่าจะเก็บไว้ที่ไหน ⭐ ห้ามข้าม

**ถ้าผู้ใช้ใส่ path มาใน `$ARGUMENTS` แล้ว ให้ใช้อันนั้นเลย ข้ามไปขั้นที่ 2**

ถ้าไม่ได้ใส่มา ให้**ถามด้วยเครื่องมือ `AskUserQuestion`** — ห้ามเดา ห้ามสร้างลงโฟลเดอร์ปัจจุบันเงียบๆ
เพราะโฟลเดอร์นี้จะกลายเป็นที่เก็บงานระยะยาว ย้ายทีหลังแล้ว path ในไฟล์เก่าจะเพี้ยน

**ก่อนถาม ต้องรู้ที่อยู่จริงก่อน** — ดูโฟลเดอร์ปัจจุบันกับโฟลเดอร์บ้านของผู้ใช้
แล้วเสนอ **path จริงที่พิมพ์ได้เลย** ไม่ใช่คำอธิบายลอยๆ

| ช่อง | ใส่อะไร |
|---|---|
| `header` | `ที่เก็บงาน` (จำกัด 12 ตัวอักษร) |
| `question` | `จะเก็บโฟลเดอร์งานไว้ที่ไหน` |
| ตัวเลือก 1 | โฟลเดอร์ปัจจุบัน — ใส่ path เต็มใน `description` ให้เห็นกับตา |
| ตัวเลือก 2 | โฟลเดอร์ใหม่ใต้โฟลเดอร์ปัจจุบัน เช่น `<cwd>/HomeyVibes-Timelapse` |
| ตัวเลือก 3 | โฟลเดอร์ใหม่ใต้บ้านของผู้ใช้ เช่น `~/HomeyVibes-Timelapse` |

ช่อง **Other** ที่ระบบเติมให้เอง = ผู้ใช้พิมพ์ path ของตัวเอง — รองรับกรณีอยากเก็บคนละไดรฟ์

**ตัวเลือก "โฟลเดอร์ปัจจุบัน" ให้เสนอเฉพาะตอนมันว่างหรือมีแต่ไฟล์ไม่กี่ไฟล์**
ถ้าโฟลเดอร์ปัจจุบันมีโปรเจคอื่นอยู่แล้ว **อย่าเสนอ** จะได้ไม่เผลอเทของลงทับงานคนอื่น

## ขั้นที่ 2 — ตรวจปลายทางก่อนก๊อป

| เจออะไรที่ปลายทาง | ทำยังไง |
|---|---|
| ไม่มีโฟลเดอร์ | สร้างแล้วก๊อปได้เลย |
| มีโฟลเดอร์แต่ว่าง | ก๊อปได้เลย |
| **มี `CLAUDE.md` หรือ `scenes/` อยู่แล้ว** | **หยุด** บอกผู้ใช้ว่าที่นี่มีโปรเจคอยู่แล้ว ถามว่าจะเอาที่ใหม่หรือจะใช้ที่มีอยู่ |
| มีไฟล์อื่นที่ไม่เกี่ยว | เตือนว่าจะก๊อปลงไปปนกัน แล้วถามก่อนทำ |

**ห้ามเขียนทับไฟล์ที่มีอยู่ในทุกกรณี** งานที่ผู้ใช้ทำมาแล้วมีค่ากว่าโครงเปล่าเสมอ

## ขั้นที่ 3 — ก๊อป

```
mkdir -p "<ปลายทาง>"
cp -r "${CLAUDE_SKILL_DIR}/../../starter/." "<ปลายทาง>/"
```

**จุดท้าย `starter/.` สำคัญ** — มันก๊อปของข้างในทั้งหมดรวมไฟล์ซ่อน ไม่ใช่ก๊อปตัวโฟลเดอร์ลงไปซ้อนอีกชั้น

ได้อะไรบ้าง:

```
<ปลายทาง>/
├── CLAUDE.md                 คู่มือที่ Claude Code อ่านเองทุกครั้งที่เปิดในโฟลเดอร์นี้
├── Timelapse_Blueprint_V1.md เหตุผลเบื้องหลังทุกขั้น + เทมเพลตพรอมต์
├── tools/                    ตัวตรวจ 2 ตัว — check-scene.mjs · check-phase-prompt.mjs
├── assets/fonts/             ฟอนต์ไทย ใช้ตอนใส่ตัวหนังสือเอง (ไม่ใช้ในคลิปที่ส่งออก)
├── products/                 คลังสินค้า ว่างอยู่
└── scenes/                   ฉาก ว่างอยู่
```

## ขั้นที่ 4 — ตรวจว่าใช้ได้จริง

รันตัวตรวจให้ดูหนึ่งครั้ง เพื่อพิสูจน์ว่า `node` เรียกได้และไฟล์ครบ:

```
node <ปลายทาง>/tools/check-scene.mjs --help
```

ถ้าเรียกไม่ได้ ให้บอกผู้ใช้ตรงๆ ว่าต้องติดตั้ง `node` ก่อน **อย่าเงียบ**
เพราะตัวตรวจคือด่านที่คู่มือบังคับให้ผ่านก่อนไปขั้นถัดไปทุกครั้ง

## ขั้นสุดท้าย — ส่งมอบ

1. บอก path เต็มของโฟลเดอร์ที่สร้าง
2. บอกว่า **ต้องเปิดเซสชันใหม่ในโฟลเดอร์นั้น** `CLAUDE.md` ถึงจะถูกอ่าน —
   เซสชันปัจจุบันยังอยู่ที่เดิม กฎในไฟล์นั้นยังไม่มีผล
3. บอกคำสั่งถัดไป: `/aff-timelapse:scene <ลิงก์ Shopee>` (ครบทั้งเส้น)
   หรือ `/aff-timelapse:product <ลิงก์ Shopee>` (ทีละขั้น)
4. เตือนว่าของที่ต้องมีก่อนเริ่มจริง: Chrome ต่อกับ `claude-in-chrome` · `ffmpeg` · บัญชี Higgsfield

## กฎเหล็ก

- **ห้ามสร้างโฟลเดอร์งานโดยไม่ถาม** ยกเว้นผู้ใช้ใส่ path มาเองใน `$ARGUMENTS`
- **ห้ามเขียนทับของเดิม** เจอโปรเจคที่ปลายทางให้หยุดถามก่อนเสมอ
- **ห้ามแก้เนื้อใน `starter/` ตอนก๊อป** ก๊อปตามต้นฉบับ ผู้ใช้ปรับเองทีหลังได้
