ถ้าไม่มีภาพ ให้หยุดแล้วบอก — สกิลนี้แก้ภาพที่มีอยู่ ไม่ได้สร้างใหม่

## ขั้นที่ 1 — Phase 2 ต้องมีของ 4 กลุ่ม

นี่คือส่วนที่พลาดกันบ่อยที่สุด **Phase 2 ที่ล้มเหลวคือ Phase 4 ที่แค่รกกว่า**
ต้องอ่านออกทันทีว่า "กำลังทำอยู่" ให้มีครบ 4 กลุ่มนี้:

| กลุ่ม | ตัวอย่าง | ทำหน้าที่อะไร |
|---|---|---|
| **ของที่ทำไปแล้วครึ่งเดียว** | ไม้ระแนงติดไป 3 แผ่นจาก 8 · เก้าอี้กางครึ่งตัว · ผนังทาสีไปครึ่งผืน | บอกว่าเสร็จไปกี่ % |
| **วัสดุกองรอ** | แผ่นไม้ที่เหลือพิงผนัง · ถุงดินยังไม่เปิด · กล่องสินค้าเปิดฝา | บอกว่าเหลืออีกเท่าไหร่ |
| **เครื่องมือ** | สว่านวางบนพื้น · กล่องสกรูเปิด · บันไดพับ · ตลับเมตร | บอกว่ามีคนทำงานอยู่จริง |
| **ของกันเปื้อน** | ผ้าใบคลุมพื้น · เทปกาวติดขอบ · กระดาษปูพื้น | ทำให้ดูเป็นงานจริง ไม่ใช่ห้องรก |

**กฎที่ทำให้ผ่าน: ระบุความคืบหน้าเป็นตัวเลข**
เขียน `3 of the 8 timber slats already fixed to the wall` ไม่ใช่ `half-finished`
คำว่า half-finished โมเดลตีความเป็น "เสร็จแล้วแต่ดูไม่เรียบร้อย" ทุกครั้ง

## ขั้นที่ 2 — คนงาน: ใส่ให้ถูกวิธี

คนคือตัวเร่งจังหวะ **ไม่ใช่ตัวเอก** และเป็นจุดที่โมเดลพังง่ายที่สุด

**ต้องมีทุกข้อ:**
- **หนึ่งถึงสองคนเท่านั้น** มากกว่านี้เฟรมรก
- `motion-blurred, mid-stride` — เบลอเพราะเคลื่อนไหว ไม่ใช่ยืนนิ่ง
- `facing away from camera` หรือ `partially cropped by the frame edge` — **ไม่เห็นหน้าชัด**
- เสื้อผ้าธรรมดา หมวกแก๊ป เสื้อยืด — ไม่ใช่ชุดยูนิฟอร์มบริษัท
- ให้คนอยู่ **ริมเฟรม** ไม่ใช่กลางเฟรม กลางเฟรมคือที่ของห้อง

**ต้องไม่มี:**
- `no clear face` · `no one looking at camera` · `no posed person`
- ไม่มีใครหยุดนิ่งชี้ของ ไม่มีใครยิ้มให้กล้อง

เหตุผลสองชั้น: กันโมเดลทำหน้าเพี้ยน (ปัญหาคลาสสิก) และกันคนดูโฟกัสผิดจุด
คนดูต้องมองห้อง ไม่ใช่มองคน

## ขั้นที่ 3 — เขียนไฟล์

> ⛔ **พรอมต์แก้ภาพที่ยาวเกินจะ Generation failed ไปเลย** ไม่ใช่แค่ผลไม่ดี
> ใช้โครง 5 บรรทัดเดียวกับ `../phase1/SKILL.md` — ไม่เกิน ~1,400 ตัวอักษร
> บรรยายสภาพปลายทางเป็นประโยคบอกเล่า ห้ามใส่พิกัด % ห้ามมีบล็อกคำสั่งห้ามยาวๆ

````markdown
# Phase 2 — ระหว่างจัด / ระหว่างทำ

ยิงที่ Higgsfield เว็บ · **โหมดแก้ภาพ ใส่ `frames/phase4.png` เป็นภาพตั้งต้น** · 9:16

```
Reference Image 1. Same <ชนิดพื้นที่>, same camera angle and position.

Scene: Mid-installation phase. <ของที่ทำไปแล้วบางส่วน พร้อมสัดส่วนเป็นคำ เช่น
the far third is already done, the near two thirds is still bare>. <วัสดุกองรอ
วางตรงไหน>. <ของกันเปื้อน คลุมตรงไหน>. <เครื่องมือ 3-4 ชิ้น วางตรงไหน>.
The finished furniture and plants are not there yet.

Subject: One worker in a cap and a plain grey t-shirt, seen from behind,
motion-blurred mid-stride, carrying <อะไร>, near the <ริมไหน> edge of the frame and
partly cropped by it.

Camera: Exact same static wide-angle position as Image 1, same <ชนิดเพอร์สเปกทีฟ>,
same framing, 9:16 vertical composition. <หมุดอ้างอิง 3-4 อย่างเป็นประโยคเดียว>
all stay in exactly the same place.

Lighting: Same <ทิศและช่วงเวลาแสง>, same <เงาเด่นๆ>, natural light only.

Style: Photorealistic, construction documentation photography, progress
documentation aesthetic.
```
````

**เรื่องคนงาน — `seen from behind, motion-blurred mid-stride` พอแล้ว**
ไม่ต้องมีบล็อก `no clear face, no one looking at camera, no posed person` ยาวๆ
วัดแล้วว่าประโยคสั้นได้ผลเท่ากันและไม่ทำให้ failed
(สังเกต: คนงานยังผ่านฟิลเตอร์ได้ปกติ — ที่ failed คือความยาวพรอมต์ ไม่ใช่การมีคนในภาพ)

## ขั้นสุดท้าย — ส่งมอบ

1. **วางพรอมต์ในกล่องโค้ดให้ก๊อปได้ทันที**
2. ย้ำว่าภาพตั้งต้นคือ `frames/phase4.png` **ไม่ใช่ phase1.png**
3. **ยิงเสร็จบนเว็บแล้วบอกได้เลย ไม่ต้องเซฟไฟล์เอง** — ดึงด้วย Higgsfield MCP
   `show_generations` แล้วโหลด `results.rawUrl` ลง `scenes/<scene-slug>/frames/phase2.png`
   (การอ่านผ่าน MCP ไม่กินเครดิต · ยืนยัน `params.prompt` ให้ตรงก่อนโหลด)
4. **บอกวิธีตรวจ 2 ข้อ:**
   - สลับดู phase1 / phase2 / phase4 เร็วๆ — ขอบผนังกับเส้นขอบฟ้าต้องไม่กระดิกทั้งสามใบ
   - ดูว่า Phase 2 "อ่านออกว่ากำลังทำอยู่" ไหม ถ้าดูเหมือน Phase 4 ที่รกกว่า = ยิงใหม่
     โดยเพิ่มตัวเลขความคืบหน้าและเครื่องมือให้ชัดขึ้น
5. ย้ำ **กฎข้อที่สำคัญที่สุดของทั้งโปรเจค**:
   > `phase2.png` จะถูกใช้สองครั้ง — เป็นเฟรมจบของคลิปที่ 1 และเฟรมเริ่มของคลิปที่ 2
   > **พอใจแล้วห้ามยิงใหม่อีก** regen แม้แต่ครั้งเดียวรอยต่อจะกระตุก
6. คำสั่งถัดไป: `/aff-timelapse:storyboard <scene-slug>`

## กฎเหล็ก

| เจออะไร | แปลว่า | ทำยังไงต่อ |
|---|---|---|
| ไม่มี `frames/phase4.png` | ยังไม่ได้ยิงภาพหมุด | หยุด บอกให้ยิง Phase 4 ก่อน **ห้ามเขียนพรอมต์สร้างภาพใหม่แทน** |
| ภาพออกมาเหมือน Phase 4 ที่รกกว่า | ไม่มีตัวเลขความคืบหน้า | ระบุเป็นตัวเลข "3 จาก 8 แผ่น" แล้วยิงใหม่ |
| หน้าคนงานเพี้ยน | ลืมสั่ง no clear face | เพิ่ม `facing away from camera, motion-blurred` แล้วยิงใหม่ |
| คนงานยืนเด่นกลางเฟรม | ลืมกำหนดตำแหน่ง | สั่งให้อยู่ริมเฟรมและถูกครอปบางส่วน |

**ห้ามเขียนพรอมต์ที่เป็น text-to-image ในสกิลนี้** — ทั้งหมดต้องเป็นพรอมต์แก้ภาพเท่านั้น
