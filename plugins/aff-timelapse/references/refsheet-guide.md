# Product Reference Sheet — 7 ขั้น

> เอกสารอ้างอิงของสกิล `refsheet` (เดิมอยู่ในปลั๊กอิน `aff` ย้ายมาไว้ที่นี่เพื่อให้ชุดนี้เป็นก้อนเดียวจบ)
> path ปลายทางในเอกสารนี้เป็นของโปรเจค timelapse แล้ว คือ `products/<slug>/` ไม่ใช่ `media-out/`

**ชีทนี้ไม่ใช่รูปโฆษณา** มันคือรูปอ้างอิงที่เอาไปแนบเป็น reference ตอนยิงภาพหรือวิดีโอรอบต่อๆ ไป
เพื่อให้โมเดลวาดสินค้า**ตัวเดิม** ทุกครั้ง ไม่ใช่วาดของหน้าตาใกล้เคียงคนละชิ้น

## ขั้นที่ 1 — หาข้อมูลสินค้า

| มีอะไรมา | ทำยังไง |
|---|---|
| path โฟลเดอร์ `products/<slug>/` | อ่าน `product.md` กับ `design.md` และดูรูปใน `seeds/` กับ `images/` |
| ชื่อสินค้าเฉยๆ | มองหาโฟลเดอร์ที่ตรงใน `products/` ก่อน ถ้าไม่เจอให้ถามผู้ใช้ว่ามีลิงก์หรือรูปไหม |
| ลิงก์ Shopee | **บอกให้รัน `/aff-timelapse:product` ก่อน** อย่าไปเก็บหน้าเว็บเองในสกิลนี้ |

ถ้ามี `design.md` อยู่แล้ว ให้ใช้ PRODUCT BLOCK ในนั้นเป็นตัวตั้ง แล้วข้ามไปขั้นที่ 3 ได้เลย —
แต่ยังต้องอ่านเพิ่มเรื่อง**สี พื้นผิว และด้านหลัง** ซึ่ง `design.md` ไม่ได้ถาม

## ขั้นที่ 2 — คัดและครอปรูปให้สะอาด

**นี่คือขั้นที่พังบ่อยที่สุด** รูปสินค้าบน Shopee เกินครึ่งมีแถบตัวหนังสือไทยแปะทับ
ถ้าเอาไปเป็น reference ทั้งดุ้น โมเดลจะลอกตัวหนังสือนั้นมาวาดใหม่เป็นอักษรบิดเบี้ยวบนชีท

1. ดูรูปใน `seeds/` ก่อน — ถ้ามีอยู่แล้วแปลว่าคัดมาแล้ว ใช้ได้เลย
2. ถ้าไม่มี ให้เปิดดูรูปใน `images/main/` และ `images/description/` ทีละรูป
3. เอารูปที่**ไม่มีตัวหนังสือ ไม่มีป้ายแปะ ไม่มีลายน้ำ ไม่มีหน้าคน**
4. **ถ้าไม่มีรูปสะอาดเลยสักรูป ให้ครอปแถบตัวหนังสือทิ้งเอง** อย่ายอมแพ้ อย่าใช้รูปที่มีตัวหนังสือ

```bash
python -c "
from PIL import Image
im = Image.open('<รูปต้นฉบับ>').convert('RGB').crop((left, top, right, bottom))
im.save('products/<slug>/seeds/<ชื่อใหม่>.jpg', quality=95)
print(im.size)
"
```

**ครอปแล้วต้องเปิดดูซ้ำเสมอ** แถบตัวหนังสือมักมีทั้งบนและล่าง และมีป้ายวงกลมมุมภาพที่มองข้ามง่าย

เป้าหมาย: ได้ **2–4 รูปสะอาด** ที่รวมกันแล้วเห็นสินค้าจากหลายมุมมากที่สุดเท่าที่มี

## ขั้นที่ 3 — ให้ ChatGPT อ่านสเปกกายภาพจากรูป

คำบรรยายต้องละเอียดกว่าที่ `design.md` เก็บไว้ เพราะชีทต้องวาดด้านหลังและพื้นผิวด้วย

```bash
printf '%s' "ดูรูปที่แนบมา แล้วบรรยายกายภาพของสินค้าเป็นภาษาอังกฤษ ย่อหน้าเดียวไม่เกิน 8 บรรทัด สำหรับใช้เป็นพรอมต์ให้โมเดลสร้างภาพวาดสินค้าชิ้นนี้ ต้องครอบคลุม รูปทรงและสัดส่วน จำนวนชิ้นส่วนหรือชั้น วัสดุแต่ละส่วน สีที่แน่นอน ลักษณะพื้นผิว ว่าเงาหรือด้าน กลไกหรือข้อต่อที่เห็น และสิ่งที่ทำให้รุ่นนี้ต่างจากรุ่นทั่วไป ถ้าเห็นด้านหลังหรือด้านข้างในรูปให้บรรยายด้วย ถ้าไม่เห็นให้บอกตรงๆ ว่ารูปไม่แสดงด้านนั้น ห้ามใส่ชื่อแบรนด์ ชื่อรุ่น ตัวหนังสือ หรือลายน้ำ ตอบเป็นย่อหน้าเดียวไม่ต้องอธิบายเพิ่ม ไม่ต้องสร้างไฟล์" | codex exec --skip-git-repo-check -i <รูป1> -i <รูป2> -
```

### ⚠️ กับดักของ codex

| ข้อ | เหตุผล |
|---|---|
| `--skip-git-repo-check` | โฟลเดอร์งานส่วนใหญ่ไม่ใช่ git repo codex จะไม่ยอมรัน |
| **ห้ามวางพรอมต์ต่อท้าย `-i`** | `-i` รับหลายไฟล์ มันจะกลืนพรอมต์ไปเป็นชื่อไฟล์ — ต้องส่งทาง stdin แล้วปิดด้วย `-` |
| **เช็ก path รูปให้ตรงก่อนยิง** | ถ้า path ผิด codex จะตอบว่า *"ไม่พบไฟล์ภาพ"* เฉยๆ **ไม่ขึ้น error** ทำให้หลงคิดว่าโมเดลอ่านรูปไม่ได้ ทั้งที่แค่ path พลาด — `ls` ดูก่อนเสมอ |

**ถ้าโมเดลบอกว่ารูปไม่แสดงด้านหลัง ให้เชื่อ** อย่าไปแต่งด้านหลังขึ้นเอง — ไปแก้ที่ขั้นที่ 4 แทน

## ขั้นที่ 4 — เลือก 4 มุมให้เหมาะกับสินค้า ⭐ ขั้นที่ตัดสินคุณภาพ

แม่แบบตั้งต้นใช้ Front / Rear / Side / Close-Up **ซึ่งใช้ไม่ได้กับสินค้าหลายประเภท**
ของที่หมุนรอบแกน (ขวด ม้วน ท่อ) ด้านหลังหน้าตาเหมือนด้านหน้า ได้ชีทที่มีสองช่องซ้ำกันเปล่าๆ

เลือกชุดมุมตามลักษณะสินค้า:

| สินค้าแบบไหน | ใช้ 4 มุมนี้ |
|---|---|
| **มีหน้า-หลังชัดเจน** (เครื่องใช้ไฟฟ้า กล่อง เคส) | Front · Rear · Side · Close-Up ตามแม่แบบเดิม |
| **ทรงกระบอกหรือหมุนรอบแกน** (ขวดน้ำยา กระป๋อง ม้วนวอลเปเปอร์) | Front · Side (90°) · Top-Down · Close-Up ของหัวจ่ายหรือฝา |
| **เป็นแผ่นหรือแผง** (สติกเกอร์ กระเบื้อง แผ่นปูพื้น) | Face-On (เต็มแผ่น) · Reverse (ด้านกาว/ด้านหลัง) · Edge-On (โชว์ความหนา) · Close-Up ลายพื้นผิว |
| **โครงสร้างที่พับหรือประกอบได้** (กรง ชั้นวาง เต็นท์) | Deployed Full · Folded/Collapsed · Side Profile · Close-Up ข้อต่อหรือกลไก |
| **ขายเป็นชุดหลายชิ้น** | Full Set Laid Out · ชิ้นหลักเดี่ยว · ชิ้นรองเดี่ยว · Close-Up จุดที่ชิ้นสองอันต่างกัน |

**กฎที่ห้ามพลาด:**

- **ต้องมีอย่างน้อย 1 มุมที่เห็นสินค้าทั้งชิ้นเต็มๆ** ไม่งั้นชีทใช้อ้างอิงสัดส่วนไม่ได้
- **Close-Up ต้องเจาะจงว่าเจาะอะไร** เขียนว่า *"close-up of the ribbed screw cap"* ไม่ใช่ *"close-up detail"*
  ปล่อยลอยๆ แล้วโมเดลจะเลือกเอง แล้วมันมักเลือกจุดที่ไม่ใช่จุดขาย
- **ถ้ารูปจริงไม่มีด้านไหนเลย ให้ตัดมุมนั้นทิ้งแล้วใช้มุมอื่นแทน** อย่าสั่งให้โมเดลเดาด้านที่ไม่เคยเห็น
  แล้วบอกผู้ใช้ในสรุปว่าตัดมุมไหนทิ้งเพราะรูปต้นทางไม่มี

## ขั้นที่ 5 — เติมช่องที่เหลือ

### `<<MATERIAL_NOTE>>` — เตือนเรื่องวัสดุที่โมเดลทำพัง

| สินค้ามีอะไร | เติมบรรทัดนี้ |
|---|---|
| ตาข่าย ซี่ ลวด ตะแกรง | `Keep every mesh opening and every wire spacing uniform and identical in all four views.` |
| ลายพิมพ์ซ้ำถี่ๆ | `Keep the repeating pattern scale, spacing and orientation identical in all four views.` |
| พลาสติกใสหรือกระจก | `Render transparency and refraction consistently; do not turn clear parts opaque in any view.` |
| โลหะเงา สแตนเลส | `Keep metal reflections soft and consistent; avoid blown-out highlights that hide the shape.` |
| ไม่มีอะไรพิเศษ | ตัดบรรทัดนี้ทิ้ง |

### `<<LABEL_EXCEPTION>>` — สินค้าที่มีฉลากพิมพ์บนตัว

แม่แบบสั่ง *"No text, labels, logos"* ซึ่ง**ขัดกับสินค้าที่ฉลากคือส่วนหนึ่งของดีไซน์**
(ขวดน้ำยา กระป๋องสี) ถ้าสั่งห้ามตัวหนังสือดื้อๆ โมเดลจะวาดขวดเปล่าไม่มีฉลาก ซึ่งไม่ใช่สินค้าจริง

- **สินค้าไม่มีฉลากพิมพ์** → ปล่อย `<<LABEL_EXCEPTION>>` ว่างไว้
- **สินค้ามีฉลากพิมพ์บนตัว** → ใส่ประโยคนี้ต่อท้าย:
  `The product's own printed label panel may appear as an abstract dark colour block with no readable lettering.`
  จะได้ขวดที่มีฉลากตรงตำแหน่งถูกต้อง แต่ไม่มีตัวอักษรมั่วให้บิดเบี้ยว

### `<<VISUAL_STYLE>>` — เลือกตามหมวดสินค้า

| หมวด | สไตล์ที่ใช้ |
|---|---|
| ของใช้ในบ้าน ของแต่งบ้าน | `photorealistic product photography, clean and neutral` |
| เครื่องมือช่าง ของยานยนต์ | `photorealistic technical product photography, crisp and utilitarian` |
| ของเกษตร ของกลางแจ้ง | `photorealistic product photography, natural and sturdy, no styling` |
| เครื่องสำอาง ของพรีเมียม | `luxury product photography, soft gradient lighting, premium finish` |

ถ้าผู้ใช้ระบุสไตล์มาเอง **ใช้ตามที่ผู้ใช้บอกเสมอ** ตารางนี้ใช้เฉพาะตอนไม่ได้ระบุ

## ขั้นที่ 6 — ประกอบแล้วเซฟ

อ่าน `${CLAUDE_SKILL_DIR}/../../references/ref-sheet-template.md` เติมช่องให้ครบ
แล้วเซฟลง `products/<slug>/refsheet.md` โดยมี:

1. **พรอมต์เต็มในกล่องโค้ดเดียว** ก๊อปไปวางได้ทันทีโดยไม่ต้องแก้อะไร
2. ตารางบอกว่าเลือก 4 มุมไหนและ**เพราะอะไร**
3. รายการรูปที่ใช้เป็น reference (path เต็ม)
4. บรรทัดบอกว่าครอปรูปไหนบ้าง ตัดตรงไหนออก (ถ้ามีการครอป)

## กฎเหล็ก

- **ห้ามแต่งกายภาพสินค้า** ถ้ารูปไม่แสดงด้านไหน ให้ตัดมุมนั้นทิ้งแล้วบอกผู้ใช้ ห้ามเดา
- **ห้ามใช้รูปที่มีตัวหนังสือเป็น reference** ครอปทิ้งก่อนเสมอ
- **ห้ามล้มทั้งงาน** ถ้า codex ใช้ไม่ได้ **ให้เขียนคำบรรยายกายภาพเองจากการดูรูป**
  แล้วบอกผู้ใช้ตรงๆ ว่ารอบนี้ไม่ได้ผ่าน ChatGPT
