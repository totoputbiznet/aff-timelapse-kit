# เก็บข้อมูลสินค้าจากหน้า Shopee — 5 ขั้น

> เอกสารอ้างอิงของสกิล `product` (เดิมอยู่ในปลั๊กอิน `aff` ย้ายมาไว้ที่นี่เพื่อให้ชุดนี้เป็นก้อนเดียวจบ)
> path ปลายทางในเอกสารนี้เป็นของโปรเจค timelapse แล้ว คือ `products/<slug>/` ไม่ใช่ `media-out/`

## ขั้นที่ 1 — เปิดหน้าสินค้าใน Chrome ของผู้ใช้

ใช้ชุดเครื่องมือ **claude-in-chrome** (Chrome จริงของผู้ใช้) ไม่ใช่เบราว์เซอร์ในแอป
เพราะ Shopee ต้องการเซสชันจริงและมีระบบกันบอท

1. `tabs_context_mcp` แล้ว `tabs_create_mcp` — **เปิดแท็บใหม่เสมอ อย่าใช้แท็บที่ผู้ใช้เปิดค้างไว้**
2. `navigate` ไปที่ลิงก์ที่ผู้ใช้ให้มา · ลิงก์ย่อ (`s.shopee.co.th/...`) และลิงก์แอฟฟิลิเอตใช้ได้ มันจะเด้งเองไปหน้าจริง
3. พอได้ URL จริงแล้ว **navigate ซ้ำไปยัง URL สะอาด** `shopee.co.th/product/<shop>/<item>` (ตัด query ติดตามทิ้ง)
4. `screenshot` เช็กว่าหน้าโหลดครบ (เห็นชื่อ ราคา ดาว จำนวนขาย)

> ⛔ **ห้ามเรียก Shopee API** (`/api/v4/pdp/get_pc`, `/api/v4/item/get_ratings`) — โดนเด้งไปหน้า verify
> แล้วเสียหน้าสินค้าทั้งแท็บ **อ่านจาก DOM ที่เรนเดอร์แล้วเท่านั้น**

## ขั้นที่ 2 — เก็บชื่อสินค้าและรายละเอียด

ใช้ `get_page_text` ทั้งหน้าทีเดียว เชื่อถือได้กว่างม DOM ทีละจุด (คลาสของ Shopee เปลี่ยนบ่อย)
เลื่อนลงไปโซน "รายละเอียดสินค้า" ก่อน เพื่อให้เนื้อหาโหลดครบ

เก็บ: ชื่อสินค้าเต็ม · ราคาปัจจุบัน/ราคาเดิม · ชื่อร้าน · คะแนน + จำนวนรีวิว · ขายแล้วกี่ชิ้น ·
ส่งจากจังหวัดไหน · หมวดหมู่ · รายละเอียด/คุณสมบัติแบบ bullet · รายการอุปกรณ์หรือตัวเลือก (ถ้ามี)

เขียนลง `products/<slug>/product.md` พร้อม **ลิงก์เดิมที่ผู้ใช้ให้มา** (ไม่ใช่ลิงก์สะอาดที่เราใช้เปิด —
ลิงก์ของผู้ใช้อาจมีรหัสติดตามแอฟฟิลิเอตอยู่ ห้ามทิ้ง) และวันที่เก็บข้อมูล

## ขั้นที่ 3 — เก็บรูปแกลเลอรีหลัก

**สโคปจาก container ของแกลเลอรี** อย่ากรองทั้งหน้า ไม่งั้นจะได้รูปรีวิวและสินค้าแนะนำติดมาด้วย

```js
const isThumb=im=>{const r=im.getBoundingClientRect();return r.width>=70&&r.width<=95&&r.height>=70&&r.height<=95;};
let main=null; for(const im of document.querySelectorAll('img')){const s=im.src||'';if(!s.includes('susercontent.com/file/'))continue;if(im.getBoundingClientRect().width>=300){main=im;break;}}
let node=main,urls=[]; for(let i=0;i<8&&node;i++){node=node.parentElement;const th=[...node.querySelectorAll('img')].filter(isThumb);
  if(th.length>=3){const seen=new Map();for(const t of th){const n=t.src.split('@')[0].replace(/_tn$/,'');const h=n.split('/file/')[1];if(h&&!seen.has(h))seen.set(h,n);}urls=[...seen.values()];break;}}
JSON.stringify({count:urls.length, urls});
```

**แถบ thumbnail เป็น carousel ที่เรนเดอร์เฉพาะรูปที่มองเห็น** ถ้ามีลูกศร `‹ ›` ต้องเก็บสะสมข้ามการเลื่อน:

1. เก็บชุดแรกก่อน — **อย่าเพิ่งคลิกลูกศร ไม่งั้นเสียรูปแรกๆ ไป**
2. เก็บ hash สะสมใน Set → คลิกลูกศรขวา → รอ ~1 วินาที → สโคปซ้ำ
3. วนจนจำนวนใน Set **นิ่ง 2 รอบติด**

ตรวจความถูกต้อง: ปกติได้ **5–10 รูป** ถ้าได้ 40–50 = สโคปพลาด ไปเอารูปแนะนำมา ให้ทำใหม่

## ขั้นที่ 4 — เก็บรูปจากรายละเอียดสินค้า (ถ้ามี)

รูปโซนนี้เป็นรูปใหญ่เต็มความกว้าง ไม่ใช่ thumbnail จึงต้องสโคปคนละแบบ
**เลื่อนลงไปให้สุดโซนรายละเอียดก่อน** เพราะรูปโหลดแบบ lazy — ไม่เลื่อนจะได้ไม่ครบ

```js
const H=document.body.innerText.indexOf('รายละเอียดสินค้า');
const out=new Map();
for(const im of document.querySelectorAll('img')){
  const s=im.src||''; if(!s.includes('susercontent.com/file/')) continue;
  const r=im.getBoundingClientRect(); if(r.width<300) continue;          // เอาเฉพาะรูปใหญ่
  const n=s.split('@')[0].replace(/_tn$/,''); const h=n.split('/file/')[1];
  if(h&&!out.has(h)) out.set(h,{url:n, top:Math.round(r.top+scrollY), w:Math.round(r.width)});
}
JSON.stringify({count:out.size, imgs:[...out.values()].sort((a,b)=>a.top-b.top)});
```

เอาเฉพาะรูปที่อยู่**ต่ำกว่า**รูปแกลเลอรีหลัก (ค่า `top` มากกว่า) และ**ไม่ซ้ำ**กับที่เก็บไว้ในขั้นที่ 3
ถ้าไม่มีเลย ให้ข้ามขั้นนี้ไปเงียบๆ แล้วระบุในสรุปว่า "ไม่มีรูปในรายละเอียด" — **ไม่ใช่ข้อผิดพลาด**

## ขั้นที่ 5 — บันทึกรูปลงเครื่อง

**ดาวน์โหลดตรงจาก URL ที่เก็บมา** ด้วยสคริปต์ที่มากับปลั๊กอินนี้ — ได้ไฟล์ต้นฉบับเต็มความละเอียด (800–1200px)

```
node ${CLAUDE_SKILL_DIR}/../../scripts/fetch-images.mjs "products/<slug>/images/main" <url1> <url2> ...
node ${CLAUDE_SKILL_DIR}/../../scripts/fetch-images.mjs "products/<slug>/images/description" <url1> <url2> ...
```

สคริปต์ตั้งชื่อไฟล์ `01`, `02`, … เรียงตามลำดับที่ส่งเข้าไป และข้ามไฟล์ที่เล็กผิดปกติให้เอง

**หลังโหลดเสร็จ ต้องเปิดดูรูปแล้วคัดทิ้ง 2 อย่าง** (สคริปต์คัดให้ไม่ได้ ต้องดูด้วยตา):

- **แบนเนอร์แคมเปญ** — ไฟล์ PNG พื้นโปร่งที่มีแต่แถบโปรโมชั่น (เช่น "8.8 ส่งฟรี ส่วนลด") ไม่ใช่รูปสินค้า
  สังเกตง่ายๆ ว่ามันมักเป็น `.png` ท่ามกลาง `.jpg` และขนาดไฟล์เล็กกว่าเพื่อนมาก
- **กล่องเทาว่างเปล่า** — placeholder ที่ยังโหลดไม่เสร็จ

ลบแล้ว**ไล่เลขไฟล์ใหม่ให้ต่อเนื่อง** แล้วบอกในสรุปว่าคัดอะไรออกไปกี่รูป

> ทำไมถึงโหลดตรงได้ — เดิมสกิลต้นทางใช้วิธีสกรีนช็อตแล้วครอป เพราะ**บนคลาวด์**ดึงรูปตรงไม่ได้
> (โดนบล็อกทั้ง CDN และ CSP) แต่ Claude Code รันอยู่**บนเครื่องผู้ใช้เอง** จึงดาวน์โหลดตรงได้
> และได้ไฟล์ชัดกว่าสกรีนช็อตมาก
